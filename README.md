# MonPix AI

Premium AI Image Tools — Upscaler & Background Remover

## Features
- **Ai Upscaler** — 1× to 16× resolution enhancement
- **Remove Background** — AI-powered precise removal
- **Before/After Slider** — Interactive comparison
- **Drag & Drop Upload** — via Uploadcare CDN
- **Dark/Light Mode** — persisted to localStorage
- **History** — localStorage-based recent results
- **Download & Copy URL** — for all results
- **Fullscreen Preview** — tap to expand
- **Toast Notifications** — success/error feedback
- **Retry Button** — on failure

## Usage
Open `index.html` in any browser. No build step required.

## APIs
- Upscaler: `https://bintangapi.full.diskon.cloud/api/tools/upscale-img`
- Remove BG: `https://bintangapi.full.diskon.cloud/api/tools/removebg`
- Uploadcare Public Key: `527f0f1c182a3ad64fd4`

## Stack
Vanilla HTML + CSS + JavaScript. No frameworks.
